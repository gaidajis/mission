# Mission

A web application for mission management and coordination.

## Overview

This project provides a platform for managing missions, user profiles, and requests. It consists of multiple HTML pages backed by a shared JavaScript application layer and CSS styling.

## Pages

| File | Description |
|------|-------------|
| `index.html` | Main landing page |
| `login.html` | User authentication |
| `app.html` | Core application interface |
| `profile.html` | User profile management |
| `request.html` | Mission request submission |

## Getting Started

### Local Development

Simply open `index.html` in your browser, or use a local static server:

```bash
npx serve .
```

### Live Demo

This project is deployed via GitHub Pages:

👉 **[https://gaidajis.github.io/mission](https://gaidajis.github.io/mission)**

## Tech Stack

- HTML5 / CSS3
- Vanilla JavaScript
- Static site (no build step required)
