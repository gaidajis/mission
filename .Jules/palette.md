## 2025-01-08 - Accessible Dynamic Inline Form Errors
**Learning:** In this vanilla JS application, form validation toggles the visibility of inline error messages (e.g., `#login-error`, `#signup-error`) using `display: none` instead of DOM insertion/removal. For screen readers to reliably announce these dynamically visible errors when they appear, `aria-live="polite"` must be explicitly added to the error message containers. Additionally, ensuring proper input-to-label association via `for` attributes is crucial for general form accessibility.
**Action:** When adding or modifying inline form validation in vanilla JS apps relying on `display` toggling, always include `aria-live="polite"` on the error container and verify `label` and `input` bindings via `for` and `id` attributes.
